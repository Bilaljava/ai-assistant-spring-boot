# 🤖 AI Assistant — Spring Boot + Groq AI

A production-ready REST API that integrates **Groq AI** (LLaMA 3.3) with **Spring Boot** to provide intelligent chat capabilities.

## 🚀 Tech Stack

- **Java 21** + **Spring Boot 3.5**
- **Groq AI API** (LLaMA 3.3 70B model)
- **RESTful API** design
- **Maven** build tool

## 📌 Features

- Natural language chat endpoint
- Fast AI responses via Groq's LPU inference
- Clean, production-ready architecture
- Easy to extend with new AI features

## 🔧 Setup

1. Clone the repository
2. Get a free API key from [console.groq.com](https://console.groq.com)
3. Set your API key in `application.properties`:
4. 4. Run the application:
```bash
   ./mvnw spring-boot:run
```
